Palworld Archipelago options

Pick your options, or start from a preset, then download your player YAML. Give the file to whoever is generating the multiworld (it goes in Archipelago's Players folder). The host also needs the Palworld APWorld installed, at the version named at the bottom of this page or newer, as an .apworld built with the project's tools/build_apworld.py (or Archipelago's "Build APWorlds"). Archipelago reads a plain zip of the APWorld folder as version 0.0.0 and refuses these files.

Player

Your name in the multiworld, up to 16 characters. {number} is replaced with a counter, for several players with the same name.

A preset fills in the options below; you can change any of them after.
